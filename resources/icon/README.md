# LibrePen Icon

Source artwork is original and lives in `icon.svg`.

- Primary mark: blue feather with a white `L` quill shaft and navy outline
- Background: light blue rounded square
- Master canvas: 1024 x 1024

Generated assets:

- `icon.ico` for Windows shell/packaging
- `icon.icns` for macOS
- `icon.png` (512 x 512) for runtime window icon
- `icon-16.png` through `icon-1024.png` for UI and store listings

The icon is an independent design and does not include the Tcl/Tk logo or other third-party artwork.
