# 07 技术路线图

## Phase 0 — 规格与基线（已完成）

交付：`docs/spec/00-09`；参考实现黑盒分析结论；技术选型与安全边界。

退出标准：架构、IPC、文件语义、MVP 范围评审通过。

## Phase 1 — MVP 可用编辑器（当前实现）

| 里程碑 | 内容 | 验收 |
|---|---|---|
| M1 工程 | Electron + Vite + TS + React + CM6；主/预加载/渲染三端构建；单实例 | `npm run dev` 启动；`npm run build` 通过 |
| M2 文件 | 打开/保存/另存/未命名/编码/换行/原子写/最近文件/会话 | 打开-编辑-保存往返；CRLF 保持；外部冲突提示 |
| M3 编辑 | CM6 + 实时预览装饰；全部命令；查找替换；源码模式 | 手动清单通过；10 万字输入流畅 |
| M4 UI | 标题栏、侧栏（文件树/大纲/搜索）、状态栏、设置、欢迎页 | 截图验收；快捷键可用 |
| M5 安全 | contextIsolation/sandbox/CSP/mdimg 协议/净化 | 渲染层无 Node；路径穿越用例被拒 |
| M6 恢复 | 自动保存 + 草稿恢复 + 关闭确认 | 强杀进程后重启可恢复 |
| M7 导出 | HTML/PDF/打印；图片粘贴 | 导出文件可离线打开；PDF 分页正常 |
| M8 质量 | Vitest 单测 + typecheck + 手动 QA | 全绿；无 P0/P1 缺陷 |

**里程碑依赖**：M1 → M2/M4 → M3 → M5/M6/M7 → M8。

## Phase 2 — 所见即所得增强

1. 表格 Widget：渲染、单元格编辑、增删行列、对齐、拖拽调整、Tab 导航。
2. 代码围栏 Widget：只读高亮 + 点击编辑 + 语言自动补全 + 行号。
3. 数学块 Widget：KaTeX 渲染、点击编辑、编号（可选）。
4. Mermaid/sequence/flow：懒渲染、主题、错误卡片、导出复用。
5. TOC Widget、脚注悬浮、front matter 面板、emoji 自动补全。
6. 主题目录兼容：`base.user.css`、`{theme}.user.css`、`current-theme.css` 变量映射。
7. 专注模式、打字机模式、块级快捷键、右键菜单、快速打开（fuzzy）。

退出标准：在 200 行混合文档中，常用块无需查看源码即可编辑；主题用户在无需改代码情况下可复用 CSS。

## Phase 3 — 文件工作流与导出

1. 图片上传适配器（PicGo CLI/自定义命令）、图片缩放/对齐菜单。
2. Pandoc 导入/导出（docx/epub/LaTeX）、Markdown 变体导出、导出图片。
3. 文件夹监听、外部修改合并提示、快速打开索引（worker）。
4. TextBundle/TextPack、多标签/多窗口同步、会话多文件恢复。
5. 打印页眉页脚、PDF 目录/元数据、导出配置 per-file。

退出标准：覆盖 Typora 文档中列出的主要导出格式；1 万文件目录搜索 < 2s（索引后）。

## Phase 4 — 生态与硬化

1. i18n（至少 zh-CN/en-US）、安装包（NSIS/MSI）、自动更新（签名）。
2. 拼写检查（系统/ Hunspell）与词典管理。
3. 插件 API（如提供）：Worker/iframe 沙箱、权限声明、能力白名单。
4. 安全审计：CSP 收紧、协议 fuzz、导出 HTML XSS 用例、依赖审计。
5. 性能：增量搜索索引、Mermaid worker、图片解码缓存。

## 风险登记

| 风险 | 影响 | 缓解 |
|---|---|---|
| CM6 装饰器与 IME/选区冲突 | 编辑体验 | 先做纯装饰、避免跨行 replace；IME 组合期暂停重建；大量手动测试 |
| 表格/代码块 Widget 复杂度 | 进度 | Phase 2 单独里程碑；先保证源码可编辑 |
| Electron 版本/打包差异 | 发布 | 锁定版本；CI 构建；printToPDF 回退方案 |
| 大文件性能 | 体验 | 2MB 上限；视口装饰；搜索/导出离屏 |
| Markdown 方言差异 | 兼容 | 以 CommonMark+GFM 为基线；扩展显式开关；测试语料 |
| 主题兼容 | 用户迁移 | 变量映射表 + 示例主题；不承诺像素级一致 |
| 安全回归 | 严重 | 默认关闭 raw HTML 执行；协议白名单；CSP；依赖审计 |

## 交付节奏建议

- 每阶段 2 个迭代：迭代 A 功能主干 + 单测；迭代 B 打磨 + QA + 文档。
- 每个 PR 必须含：变更说明、测试、截图（UI）、安全影响（如涉及 IPC/协议）。
- 版本号：`0.1.0` MVP；`0.2.0` Phase 2；`0.3.0` Phase 3；`1.0.0` 功能对等子集 + 打包。
