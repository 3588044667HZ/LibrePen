# 11 扁平化 UI（0.2.1）

## 1. 目标

- 去掉卡片化：无圆角卡片、无阴影、无悬浮面板背景。
- 编辑区全宽：除表格外，标题/正文/代码/公式/图/目录/Front Matter 占满编辑区宽度。
- 边框只用于内容语义：**表格、代码块、引用**。其他内容块只用间距、字体和颜色区分。
- 编辑界面只保留：顶部菜单栏 + 编辑器 + 可选侧栏。移除状态栏、欢迎页卡片、侧栏底部按钮组。
- 图标统一 Bootstrap Icons。
- 新建/打开/保存/导出/设置等入口放到顶部菜单。

## 2. 布局

```text
┌──────────────────────────────────────────────────────────────┐
│ 文件 编辑 段落 格式 视图  [侧栏][源码]   文件名        ─ □ ×  │  36px 顶栏
├───────────────┬──────────────────────────────────────────────┤
│ 文件 大纲 搜索 │  Front Matter（无卡片）                       │
│ 文件树/最近    │  # 标题                                       │
│               │  正文（全宽）                                 │
│               │  ``` 代码块（允许边框）                        │
│               │  | 表格 |（允许边框）                          │
│               │  > 引用（允许左边框）                          │
│               │  $$ 公式 $$（无边框）                          │
│               │  Mermaid（无边框）                             │
└───────────────┴──────────────────────────────────────────────┘
```

- 无状态栏；字数/编码等统计不再常驻界面。
- 无欢迎页；启动无文件时直接创建「未命名」空白编辑器。
- 侧栏可选；无文件夹时显示最近文件，不再显示底部按钮。
- 顶栏使用自绘菜单；侧栏与源码模式为图标按钮（`bi-layout-sidebar-inset` / `bi-code-slash`）；窗口按钮使用 Bootstrap Icons（`─ □ ×`）。

## 3. 样式规则

| 区域 | 规则 |
|---|---|
| 内容宽度 | `.cm-content` 宽度 100%，无 max-width；行内边距 16px |
| 普通块 | 无 border / border-radius / background / shadow |
| 表格 | 1px 单元格边框；表宽默认 `100%`，可拖拽列宽/行高，单元格内联 Markdown；长命令换行 |
| 代码块 | 1px 外边框；工具栏无背景；代码区 `--code-bg` |
| 引用 | 2px 左边框 |
| 块工具栏 | 透明背景、无边框、默认 55% 透明度，hover/focus 100% |
| 块操作 | Bootstrap Icons，仅图标 + title/aria-label |
| 侧栏 | 无右边框；选中项用背景色，不使用圆角卡片 |
| 菜单 | 无圆角、无阴影；下拉用 1px 边框分隔 |
| 对话框 | 无圆角、无阴影；仅保留必要边框 |
| 图标 | `bootstrap-icons` 字体，`<i class="bi bi-*">` |

## 4. 交互入口

顶栏菜单：

- **文件**：新建、打开、打开文件夹、快速打开、保存、另存为、恢复最近草稿、导出 HTML/PDF、打印、设置
- **编辑**：撤销、重做、查找、替换
- **段落**：标题 1–3、正文、引用、代码块、公式块、表格、水平线、目录
- **格式**：加粗、斜体、下划线、删除线、高亮、行内代码、链接、图片
- **视图**：侧栏、源码模式、专注、打字机、浅色/深色/跟随系统、设置

快捷键仍由原生菜单 accelerator + 编辑器 keymap 提供；`Ctrl+P`、`Ctrl+,` 有渲染层兜底。

## 5. 验收

1. 启动后无欢迎卡片；无文件时出现「未命名」空白编辑器。
2. 顶栏可见「文件 编辑 段落 格式 视图」，点击可展开菜单并执行新建/设置。
3. 窗口右上角有 Bootstrap Icons 窗口按钮（Windows）。
4. 打开混合文档：仅代码块、表格、引用有边框；Front Matter/TOC/公式/Mermaid 无卡片。
5. 标题/正文/代码/公式/图/目录水平方向占满编辑区；表格可窄于视口。
6. 无状态栏；专注/打字机只能从「视图」菜单或 F8/F9 触发。
7. 侧栏无底栏按钮；新建/打开在顶栏菜单。
8. 所有块操作按钮为 Bootstrap Icons，hover 时显示 title。
9. 标题不再出现下划线（覆盖 CodeMirror 默认 heading 样式）。
10. 快速打开、主题、表格面板、右键菜单仍可用。

## 6. 例外

- 表单控件（设置/表格面板 input）、菜单下拉、对话框保留必要的 1px 边框以区分层级。
- 表格允许横向滚动；窄屏时表格可滚动而不是压缩内容。
- 主题 CSS 可能引入自定义边框/背景；用户主题自行负责。
