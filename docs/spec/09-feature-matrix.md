## 6. MVP 验收剧本

1. 启动 → 欢迎页显示最近文件。
2. 打开 `demo.md`（含标题、粗体、链接、图片、公式、任务、代码、表格）。
3. 验证：标题/粗体/链接/图片/公式/复选框正确渲染；移动光标标记还原。
4. 修改内容 → 状态栏变「未保存」→ `Ctrl+S` → 文件落盘、mtime 更新、状态恢复。
5. 关闭窗口 → 取消 → 再次关闭 → 不保存 → 重启 → 恢复草稿出现。
6. 打开文件夹 → 文件树展开 → 大纲跳转 → 搜索关键词并跳转。
7. 粘贴剪贴板图片 → `assets/` 出现文件 → 编辑器显示图片。
8. 导出 HTML → 离线打开 → 样式/公式/图片正常。
9. 导出 PDF → A4 → 打开检查分页与字体。
10. 切换深色主题 → 重启 → 主题保持。
11. 源码模式切换 → 文档内容不变。
12. 快捷键：粗体、标题、列表、查找替换、侧栏。

全部通过即视为 MVP 验收完成；未通过项记录 issue 并标注阶段。
