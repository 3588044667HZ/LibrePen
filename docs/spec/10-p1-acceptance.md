## 2. 手动验收步骤

1. 启动后打开一个包含 front matter、`[toc]`、代码块、表格、公式、Mermaid、任务列表的文档。
2. 确认六个块渲染为卡片/组件；滚动时 Mermaid 最终显示 SVG。
3. 点击代码块正文 → 内嵌编辑区出现，输入时实时高亮；点击块外或「完成」提交；按 Esc 取消；「编辑源码」可回到围栏源码。
4. 打开含表格的文件，确认表格无需点击即渲染；单元格内反引号代码显示为等宽代码；拖动列边界/行边界调整尺寸，点工具栏重置按钮恢复；点击单元格 → 面板打开；修改表头为 `Header X`，点「应用」→ 表格更新；点「源码」→ Markdown 中包含 `Header X`。
5. 点击 TOC 条目 → 滚动到对应标题。
6. 点击「编辑源码」编辑公式，改回后渲染。
7. 通过「视图」菜单打开/关闭「专注」「打字机」（或 F8/F9），确认样式/滚动变化。
8. Ctrl+P 打开快速打开，输入文件名片段，Enter 打开文件。
9. 设置 → 外观 → 自定义主题：把任意 CSS 放入 `%APPDATA%\LibrePen\themes\`，刷新并选择，确认样式生效。
10. 输入 `:sm` 与代码围栏语言，确认自动补全。
11. 在编辑区右键，执行一次加粗/表格命令，确认生效。
12. 点击顶栏 `bi-code-slash` 图标或按 Ctrl+/ → 所有块回到 Markdown 源码（等宽字体）；再次点击 → 块恢复；重启后源码模式状态保持。
13. 用搜索跳转到代码块内的命中位置，确认自动展开源码并定位。
